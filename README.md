# What is it?
This is a platform based on HustOJ, like <a href="https://www.codingame.com/multiplayer/clashofcode">Clash of code</a> service.

You only need run `src/install.sql` in mysql, then you can run this project.

# How install?
You need install hustoj first (zhblue/hustoj).
Then, clone this repo in `/home/judge/src/web`, open https://your-web-site.com/your-fastcoding-folder/install.php, enter install, or run `src/install.sql` in mysql by yourself.
After all actions, you can use your fastcoding program!
